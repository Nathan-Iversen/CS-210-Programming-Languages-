# CS-210-Programming-Languages-
**1.	Summarize the project and the problem it was solving.**
This project involves a hypothetical grocery store that needs a program to track the items purchased from its produce section. Grocery store leadership plans to rearrange the produce section depending on how many products are sold throughout the day. The list of items sold within a day is included in a text file. The program reads a text file, maps each item to its purchase frequency, and generates reports to help analyze the data. Additionally, the program creates a backup file containing each item’s name and its corresponding frequency as a numerical value. 

**2.	What did you do particularly well?**
One aspect that I did particularly well was organizing the program into separate functions. This provided the benefit of ensuring my code is maintainable, readable, and easily reusable. I also utilized a map to efficiently track each item’s frequency. This allowed the program to search for items and generate reports without needing to repeatedly process the original data. Additionally, I implemented rigorous input validation and error handling. This ensures that the program operates reliably and produces accurate results.

**3.	Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?**
One area where I could enhance the code is to account for the singular form of names while searching for an item. The provided text document lists each item in its plural form, so searching for an item using its singular form may not return the expected results. The program already accounts for variations in uppercase and lowercase letters, as well as unintentional spaces. However, additional rules are needed to convert a singular search term to its corresponding plural form. Due to the number of plural forms in the English language, this improvement would require additional logic to handle each case correctly. This improvement would increase the flexibility of the search function and improve the overall user experience.

**4.	Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?**
The most challenging part of developing the program was generating a report that included each item stored in a map. The course material did not cover how to implement and iterate through a map beyond some optional additional content. To overcome this, I reviewed the additional content as well as outside sources. One resource that I'm adding to my support network is https://www.w3schools.com/. The C++ Maps section provides straightforward information on how to iterate through a map and output both the keys and values. This resource was especially useful in helping me understand how to implement this functionality for the project.

**5.	What skills from this project will be particularly transferable to other projects or coursework?**
Several skills from this project will be transferable to future projects and coursework. Being able to organize code into separate functions is especially useful. Ensuring a program is maintainable, readable, and adaptable is a crucial aspect of any software project. Utilizing a map to store and retrieve data efficiently also has many useful applications. Additionally, learning how to research unfamiliar concepts will be valuable when working on programming projects in the future.

**6.	How did you make this program maintainable, readable, and adaptable?**
Organizing the program into separate functions made the program more maintainable, readable, and adaptable. It increased readability by not including everything in the main function. Each function also describes its exact purpose, so the entire code doesn’t need to be analyzed to understand what the code is doing. Functions also make the code easier to modify. If a program performs the same process multiple times, using a function allows changes to be made in one place rather than updating multiple sections of code. Functions also make the program simpler to troubleshoot. If a function performs incorrectly, the section that needs improvement is easier to identify. Additionally, implementing a class to track items purchased from the produce section makes the code reusable. With minimal modifications, the class could be adapted to track purchases in other departments.
